🪜 Install, step by step

  1. Install Node.js (if you don't have it)

    Download the LTS version from nodejs.org and install it like any app. To check it worked, open a terminal and type:

    node --version — you should see a number like v22…

  2. Install opencode

    In the terminal, run:

    npm install -g opencode-ai

    Full install guide with other options: opencode.ai/docs

  3. Connect a free model

    Run opencode auth login and follow the steps on screen. We use the free model your instructor shows in class — ask if you're not sure which one to pick.

  4. Open a project and say hi

    Go into any project folder and start it:

    cd my-project then opencode

    First question to ask it: "What does this project do?" 😉

  5. 📸 Proof time

    Screenshot opencode answering your first question — that's your setup proof for the portfolio. Then tick the mission on the task board!

🆘 If something breaks

  • "command not found" after install → close the terminal and open a new one.
  • Permission errors on install → ask your instructor; we fix it together in 2 minutes.
  • Stuck 5 minutes? Ask. That's the rule. 💜
