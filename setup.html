🪜 Install, step by step

  1. Install Node.js (if you don't have it)

    Download the LTS version from nodejs.org and install it like any app. To check it worked, open a terminal and type:

    node --version — you should see a number like v22…

  2. Install opencode

    In the terminal, run:

    npm install -g opencode-ai

    Full install guide with other options: opencode.ai/docs

  3. Connect a free model

    Run opencode auth login and follow the steps on screen. We use the free models (the ones marked free in the model list — $0). Ask Yan which one we're using this week.

  4. Open a project and say hi

    Go into any project folder and start it:

    cd my-project then opencode

    First question to ask it: "What does this project do?" 😉

  5. Turn on your cost radar 💸

    opencode can tell you how many tokens you used and what they cost. Try:

    opencode stats — all your sessions · opencode stats --days 7 — this week

    Make it a habit: check your stats at the end of every lesson. On free models the cost is $0 — and we keep it that way. 😎

  6. 📸 Proof time

    Screenshot opencode answering your first question + your opencode stats — that's your setup proof for the portfolio. Then tick the mission on the task board!

🔤 What is a token? (watch it happen)

AI doesn't read words — it reads tokens: little pieces of words. Every message you send and every answer you get is counted in tokens. And tokens are what you pay for.

This is a friendly imitation — real tokenizers split even smarter. Try the real one: platform.openai.com/tokenizer. Prices are examples per 1 million tokens — they change all the time; always check the model list.

💡 One chat message ≈ tens of tokens. A coding agent reading your whole project ≈ tens of thousands. That's why pros watch their token use — and why opencode stats exists.

Same prompt, different models 🌸

We give each one our explicit flower-shop prompt. What usually happens:

Free modelA good basic site. Might miss a detail or two — guide it, ask again. Cost: $0.
Haiku-classQuick and clean on small asks; split big jobs into steps for it. Cost: tiny.
Sonnet-classSolid site on the first try — understands the whole plan. Cost: cents.
Opus-classAlso nails the tricky parts (form checks, edge cases). Cost: the most.
👑 Our rule: start free, upgrade only when you're stuck — and check opencode stats before and after. Try the same prompt on two models and compare: that's a real engineer's experiment.

🚀 Put your app online — Vercel (free)

A project on your laptop is homework. A project with a LINK is a product. 💅

  1. Push your project to GitHub

    Your code needs to live in a GitHub repo first (we do this in class).

  2. Sign in to Vercel with GitHub

    Go to vercel.com → Continue with GitHub → pick the Hobby plan (that's the free one).

  3. Import & deploy

    Add New → Project → pick your repo → Deploy. That's it.

  4. Share your link 🎉

    You get your-project.vercel.app — send it to everyone. Every push to GitHub updates the site automatically.

🚨 Free-tier rules (really important)

  • This year we use FREE tiers only — Vercel Hobby, opencode free models, Mongo free cluster.
  • Never enter a credit card. If a site asks for one — stop and tell Yan.
  • Before you click, check the plan name says Free or Hobby.
  • A "free trial" that wants a card is NOT free. Skip it.
  • See an "upgrade" popup or a price? Screenshot it, close it, ask in class.

Real engineers get surprise bills too. 😅 The habit of checking first is the skill.

🆘 If something breaks

  • "command not found" after install → close the terminal and open a new one.
  • Permission errors on install → ask your instructor; we fix it together in 2 minutes.
  • Stuck 5 minutes? Ask. That's the rule. 💜
