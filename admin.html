🔑 Sign in with GitHub

This page talks straight to the GitHub API from your browser. Your token is stored only on this device — it never goes to any server except github.com.

  1. Create a fine-grained token (once)

    Open github.com → Settings → Fine-grained tokens.
    Repository access: Only select repositories → alicecode-level4-hub.
    Permissions: Contents → Read and write. Nothing else.

  2. Paste it here

🔒 Lesson locks

Locked lessons disappear from the students' pages (lessons, calendar, tasks, direct links). You always see everything.

⏱️ After you flip a switch, students see the change when GitHub Pages redeploys — usually under a minute.

View site as instructor

🛡️ Good to know

The lesson content lives in a public repository, so locking hides it from the site — it isn't encryption. For a class of curious 14-year-olds that's exactly enough mystery. 😉 If a token ever leaks, revoke it in GitHub settings; it can only touch this one repo.
